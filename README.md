# kbeauty-cs-agent

가상의 K-뷰티 이커머스 고객사를 대상으로 **AI 고객 상담 에이전트**와 그 에이전트가 연동할 **고객사 시스템**을 직접 설계하고 구현하는 학습 프로젝트입니다.

## 이 프로젝트의 성격

- **개인 학습 프로젝트입니다.**
- 등장하는 고객사, 상품, 주문, 고객 문의는 **전부 가상으로 생성한 데이터**입니다.
- 작업 기간: **2026년 8월 20일 ~ 8월 23일**

## 목표

Forward Deployed Engineer(FDE)의 업무를 코드 수준에서 미리 경험하는 것이 목적입니다. 구체적으로 다음 다섯 가지를 이해하는 것을 목표로 합니다.

1. FDE가 정확히 어떤 일을 하는가
2. 구체적으로 어떤 업무를 수행하게 되는가?
3. 그 과정에서 마주하게 되는 문제로는 어떤 것들이 있는가?
4. AI 기반 고객 대응 시스템이 내부적으로 어떻게 동작하는가?
5. 고객사 시스템이 일반적으로 어떻게 생겼고 어떻게 돌아가는가?

## 진행 방식
아주 단순한 가정으로부터 시작해 점진적으로 전체 시스템을 구체화해가는 점진적 하향식 설계(gradual, top-down approached system design)를 통해 학습하기로 했습니다.
직접 바닥부터 시작해 만들어보며 고도화하는 과정에서 자연스레 주된 문제와 고민을 이해할 수 있다고 판단했기 때문입니다.

설계상의 모순뿐 아니라 **실제로 돌려 봤을 때 드러난 문제**에서도 다음 층을 도출합니다.

```
층 0  고객사와 코어 AI 엔진(자사 솔루션) 두 가지를 두고, 고객사의 CS 대응을 자사 AI 솔루션으로 자동화하기 위해선 무엇이 필요한지 고민합니다.
층 1  두 시스템 간 연동을 어떻게 설계해야할지 고민해보고 직접 만들어봅니다.
층 2  자사 솔루션의 AI 코어 엔진 내부 분해 → 고객사의 CS 대응을 처리하는 코어 루프 구현해보기
      ↓ 전환 1: 고객사 시스템 파악 (주어진 것을 읽는 작업)
      ↓ 전환 2: 문의 300건 분류 (데이터 -> 귀납적 추론을 통해 고객사의 정책 및 암묵지를 파악해 결정적인 의사 결정 체계로 만들어보기)
층 3  연동부 분해 → 어댑터 구현
      ↓ 전환 3: 장애 주입
층 4  운영 층 (오퍼레이션 콘솔, 회귀 검증)
층 5  FDE 업무 온보딩 5단계 밟기
```

## 기술 구성

| 영역 | 언어 |
|---|---|
| 에이전트 엔진 | Python |
| 고객사 시스템 모의 구현 | Python (FastAPI) |
| 오퍼레이션 콘솔 | JavaScript |

LLM은 Anthropic Claude API를 사용합니다.

# kbeauty-cs-agent

가상의 K-뷰티 이커머스 고객사를 대상으로 **AI 고객 상담 에이전트**와 그 에이전트가 연동할 **고객사 시스템**을 직접 설계하고 구현하는 학습 프로젝트입니다.

## 이 프로젝트의 성격

- **개인 학습 프로젝트입니다.** 특정 회사의 제품이 아니며, 어떤 회사의 내부 정보도 포함하지 않습니다.
- 설계의 출발점이 된 정보는 **공개된 홈페이지와 언론 보도뿐**입니다.
- 등장하는 고객사, 상품, 주문, 고객 문의는 **전부 가상으로 생성한 데이터**입니다.
- 작업 기간: **2026년 8월 20일 ~ 8월 23일**

## 목표

Forward Deployed Engineer(FDE)의 업무를 코드 수준에서 미리 경험하는 것이 목적입니다. 구체적으로 다음 다섯 가지를 이해하는 것을 목표로 합니다.

1. FDE가 정확히 어떤 일을 하는가
2. 구체적으로 어떤 작업을 손에 쥐게 되는가
3. 그 과정에서 어떤 어려운 문제에 부딪히는가
4. 가상 CS 직원 서비스가 내부적으로 어떻게 동작하는가
5. 고객사 시스템이 일반적으로 어떻게 생겼고 어떻게 돌아가는가

## 진행 방식

하향식 설계(top-down design)를 뼈대로, 각 층마다 설계와 구현을 번갈아 진행합니다. 설계상의 모순뿐 아니라 **실제로 돌려 봤을 때 드러난 문제**에서도 다음 층을 도출합니다.

```
층 0  상자 세 개 (고객 / 엔진 / 고객사 시스템)
층 1  경로가 생긴 그림 (채널, 연동부)
층 2  엔진 내부 분해 → 코어 루프 구현
      ↓ 전환 1: 고객사 시스템 파악 (주어진 것을 읽는 작업)
      ↓ 전환 2: 문의 300건 분류 (데이터에서 의도 체계 귀납)
층 3  연동부 분해 → 어댑터 구현
      ↓ 전환 3: 고장 주입
층 4  운영 층 (오퍼레이션 콘솔, 회귀 검증)
층 5  온보딩 5단계 밟기
```

## 기술 구성

| 영역 | 언어 |
|---|---|
| 에이전트 엔진 | Python |
| 고객사 시스템 모의 구현 | Python (FastAPI) |
| 오퍼레이션 콘솔 | JavaScript |

LLM은 Anthropic Claude API를 사용합니다.

# 발견한 문제 목록

목표 3의 최종 산출물. **실제로 만들어 돌려 보다가 부딪힌 문제**를 누적한다.
설계 단계에서 예상한 것이 아니라, 실행 중에 드러난 것만 적는다.

각 항목은 다음 형식으로 쓴다.

```
## [번호] 제목

- **언제**: 어느 층 / 전환에서
- **무슨 일이 일어났는가**: 관찰한 사실
- **왜 일어났는가**: 원인
- **어떻게 다뤘는가**: 대응
- **일반화하면**: 이 문제가 속하는 문제의 종류
```

마지막 항목이 가장 중요하다. 언어와 도메인이 바뀌어도 남는 것은 그것이다.
